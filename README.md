# Autonomous Driving System

Camera-only lane keeping in the [MetaDrive](https://github.com/metadriverse/metadrive) simulator, a
multi-task YOLO11 perception model on BDD100K, and TensorFlow Lite export for edge inference.

* **Steering:** a PilotNet-style CNN (PyTorch, OpenCV preprocessing) predicts the steering angle from
  a single forward camera. It is trained on frames collected with DART noise injection and evaluated
  in closed loop on 1,000 procedurally generated test roads against an expert baseline.
* **Perception:** one YOLO11 backbone with three heads: object detection over 12 classes,
  drivable-area segmentation and lane-line segmentation, compared against a classic OpenCV lane
  pipeline.
* **Edge:** export to TensorFlow SavedModel and TFLite INT8 with a latency benchmark, and a
  cross-dataset check of the steering model on real dashcam footage.

The design, metric definitions and dataset roles are in [docs/PLAN.md](docs/PLAN.md).

## Setup

Python 3.11 (MetaDrive 0.4.3 supports Python below 3.12).

```bash
python -m venv .venv
.venv/Scripts/python -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu118
.venv/Scripts/python -m pip install -e ".[sim,yolo,tf,dev]"
.venv/Scripts/python -m metadrive.pull_asset
python tools/render_check.py --out docs/media/first_frame.jpg
```

Use the CUDA build that matches your driver, or the CPU build. The CUDA 11.8 build above still ships
kernels for older GPUs (compute capability 3.7 and up); it was verified here on a GeForce MX110
(compute capability 5.0) with driver 512.78, which reports CUDA 11.6.
Camera rendering in MetaDrive needs a working OpenGL GPU driver; software rendering is far too slow
for data collection. `tools/render_check.py` saves one frame and reports the OpenGL renderer and the
stepping rate.

Windows notes:

* PyTorch needs the Microsoft Visual C++ 2015–2022 x64 runtime.
* The MetaDrive 0.4.3 wheel contains example logs whose paths exceed the 260-character limit under a
  typical venv. Either enable long paths, or install a copy of the wheel without them using
  [tools/strip_wheel_long_paths.py](tools/strip_wheel_long_paths.py).

## Steering pipeline

```bash
python -m ads.sim.collect --split train --target 75000
python -m ads.sim.collect --split val --target 6000
python -m ads.dataset
python -m ads.train --out runs/steering/pilotnet
python -m ads.eval.closed_loop --driver model --model runs/steering/pilotnet/best.pt --out runs/closed_loop/pilotnet --videos 5
python -m ads.eval.closed_loop --driver expert --model runs/steering/pilotnet/best.pt --out runs/closed_loop/expert
```

## Layout

```
ads/
  config.py            seed splits, road suite, camera geometry, evaluation settings
  sim/env.py           MetaDrive environment for the lane-keeping road suite
  sim/expert.py        IDM expert driver
  sim/collect.py       DART data collection, resumable per seed
  steering/preprocess.py  crop/resize/YUV and OpenCV augmentation
  dataset.py           memory-mapped frame cache and inverse-frequency loss weights
  model.py             PilotNet with a speed input
  train.py             training with early stopping
  eval/metrics.py      autonomy, Wilson intervals, per-km rates, jerk, open-loop splits
  eval/closed_loop.py  closed-loop evaluation with a safety driver
tests/                 unit tests that run without the simulator
tools/                 render and frame-timing checks, Windows install helper
```

## Testing

```bash
ruff check . && pytest -q
```

The unit tests cover metrics, preprocessing, model shapes, seed-split disjointness and the DART noise
process. MetaDrive is imported lazily, so the tests run without the simulator.
